### Dispatch Service
- [x] getEligibleRiders: Filters by ONLINE status, KYC approved, vehicle compatibility, zone/distance
- [x] assignRider: Validates rider eligibility, updates delivery and rider status
- [x] reassignRider: Handles reassignment with reason, updates old/new rider statuses
- [x] getLiveDeliveryBoard: Returns all active deliveries for admin
- [x] getRiderQueue: Returns rider's assigned deliveries
- [x] riderAcknowledgeJob: Rider acknowledges assigned job
- [x] updateRiderLocation: Real-time location tracking
- [x] setRiderStatus: Validates status transitions (ONLINE ↔ OFFLINE ↔ ON_TRIP)
- [x] Vehicle compatibility logic (motorcycle ≤10kg, van ≤50kg, truck ≤200kg)
- [x] Distance calculation (Haversine formula)

### API Endpoints
**Admin:**
- [x] GET /dispatch/board - Live delivery board
- [x] GET /dispatch/:deliveryId/eligible-riders - Get eligible riders for assignment
- [x] PUT /dispatch/:deliveryId/assign - Assign rider to delivery
- [x] PUT /dispatch/:deliveryId/reassign - Reassign rider with reason

**Rider:**
- [x] GET /dispatch/my-queue - Get rider's assigned deliveries
- [x] POST /dispatch/:deliveryId/acknowledge - Acknowledge assigned job
- [x] PUT /dispatch/location - Update rider location
- [x] PUT /dispatch/status - Update rider status (ONLINE/OFFLINE/ON_TRIP)
