### State Machine Transitions (Validated)
| Current Status | Allowed Next Statuses | Actor |
|----------------|----------------------|-------|
| REQUESTED | SEARCHING, CANCELLED | system, customer |
| SEARCHING | ASSIGNED, CANCELLED | admin, customer |
| ASSIGNED | PICKED_UP, CANCELLED | rider, customer |
| PICKED_UP | IN_TRANSIT, FAILED | rider |
| IN_TRANSIT | DELIVERED, FAILED | rider |
| DELIVERED | (terminal) | - |
| FAILED | RETURNED, SEARCHING (redelivery) | rider, admin |
| RETURNED | (terminal) | - |
| CANCELLED | (terminal) | - |
